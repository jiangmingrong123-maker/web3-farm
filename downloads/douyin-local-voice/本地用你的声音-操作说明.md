# 没法把声音发给我？就地在剪映换声

你这边传不了语音/带声视频也没关系。我已经准备好 **无声画面版**，你在手机剪映里自己录口播盖上去即可。声音全程不出你的手机。

## 今天最快发 1 条（约 10–15 分钟）

用第 **01** 集试水：

1. 把 `videos-silent/01-27块 vs 1360块-无声.mp4` 存到手机相册  
2. 打开 **剪映** → 新建草稿 → 导入这条无声视频  
3. 点底部 **录音**（或「音效 → 录音」）→ 对着屏幕念下面这段：

```
同样拍一集五分钟、角色会开口说话的 AI 短剧。
有人视频这一步要一千三百多，我这边算下来大概二十七块。
差别在哪？不是偷工减料，是选对模型和跑法。
一个人，不用买显卡，也能做出会说话的短剧。
关注我，下一集把工具分工讲清楚。
```

4. 录完听一遍；不满意就重录这一条，不用重做画面  
5. 导出竖屏 → 抖音上传  
6. 标题/描述从 `publish/发布文案一键复制.md` 第01集复制  
7. 勾选 **AI生成** → 发布

## 可选：对着提词器录（字更大）

手机浏览器打开 `teleprompter/提词器-12集.html`，点 01，边看大字边在剪映里录音。

## 两条路怎么选

| 路径 | 适合 | 结果 |
|---|---|---|
| A. 无声版 + 剪映录音（推荐） | 想用你自己的声音 | 你的声线 + 现成画面字幕 |
| B. 直接发 `videos/` 有声版 | 今天先上号、声音以后再换 | 女声占位，也能发 |

建议先发：**01 → 03 → 08**。

## 注意

- 录音时尽量安静，语速跟字幕差不多即可  
- 不用发给我任何音频；本地导出直接上抖音  
- 若某条无声视频时长偏短/偏长，以字幕节奏为准，录音时可暂停视频重来
