# 怎么把你的声音传给我（不用标准念稿）

目标：**你随便自然说一段** → 我提取声线 → **用你的声音生成标准口播** → 盖到动画视频上。  
你不用把整集稿子读得很好，也不用读完整稿。

## 你录什么

- 时长：**30–60 秒**（有 1–2 分钟更好）
- 内容：日常说话即可，讲今天吃了啥、讲工作都没事
- 语气：正常聊天就行，别刻意播音
- 环境：尽量安静，少回音
- 格式：`.m4a` / `.mp3` / `.wav` / `.MOV` 都行（网盘可传视频）

## 怎么发（网盘）

1. 上传到 夸克 / 阿里云盘 / iCloud / Google Drive / Dropbox  
2. 开 **任何人可下载**（或把提取码一起发我）  
3. 把链接发到这个对话  

收到后我会：抽音轨 → 克隆声线 → 生成第 01 集标准口播 → 合成动画版成片给你下载。

## 为什么 Cursor 里直接传不行

- `.MOV` 视频会被拒（`not a supported document type`）  
- 语音通话录音也落不到我这边  
所以用网盘最稳。

## 备选：你本地盖声音

若暂时不克隆，也可下 `01-动画版-无声.mp4`，在剪映里自己录音。  
但按你的需求，**优先走网盘样本 + 我生成标准读法**。
