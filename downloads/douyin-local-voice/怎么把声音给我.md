# 怎么把你的声音传给我

语音通话录音、带声音的视频，这边经常收不到。用下面任一方式即可。

## 方法 1：Cursor 聊天「附加文件」（优先试）

1. 手机「语音备忘录」录那段口播，导出/存储为 `m4a` 或 `mp3`
2. 打开 Cursor 对话 → 点 **+ / 附加 / Files**
3. 从「文件」里选这个音频（不要选视频，视频传不了）
4. 发一句：「这是我的声纹，盖到第01集动画版」

> 需要 Cursor App 较新版本（支持任意文件类型附件）。

## 方法 2：网盘链接

把 `m4a/mp3` 传到 夸克 / 阿里云盘 / Google Drive / Dropbox，开启「任何人可下载」，把链接发我。

## 方法 3：传到这个 GitHub 仓库

把音频文件上传到本目录（或发我文件，我帮你放）：

`downloads/douyin-local-voice/my-voice.m4a`

## 方法 4：不传给我（本地盖声音）

直接下 `01-动画版-无声.mp4` → 剪映录音 → 导出。声音不出手机。
