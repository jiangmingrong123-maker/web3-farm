# 知己知彼 · 识人模型总表

> 整理自讨论：以「自我估值准不准」定义知己，以「对别人虚实/识破的判断」定义知彼；衡量靠可复盘误差，不靠感觉。

---

## 一、总览总表（一张看懂）

| 维度 | 明弈型 | 孤岛型 | 镜人型 | 迷雾型 |
|------|--------|--------|--------|--------|
| **坐标** | 知己 × 知彼 | 知己 × 不知彼 | 不知己 × 知彼 | 不知己 × 不知彼 |
| **你的核心画像** | 可能吹很大，但知道自己在吹；也清楚别人不容易拆穿 | 一般不吹牛，常低估自己 | 对自己账糊，但对别人虚实嗅觉灵 | 有10当12花，用虚高自我定义过日子 |
| **知己含义** | 估值准，且能标出包装比例 | 对自己相对清楚（常偏保守） | 宣称≠事实，且说不清自己在包装 | 估值漂了还当真 |
| **知彼含义** | 知道别人能不能拆、别人吹了多少 | 对「别人怎么看、能看穿什么」没谱 | 能较准看出别人是10还是12 | 看不清别人虚实 |
| **吹牛表现** | 敢吹、战略吹、自觉吹 | 少吹、压着说 | 可能吹也可能不吹，但不自知 | 当真吹 / 当真虚高生活 |
| **生活隐喻** | 有10，必要时按12讲，心里清楚是包装 | 有10，常按8讲 | 自己可能当12，但能看出别人只有10 | 有10，一直觉得有12，按12花 |
| **浅/深知彼** | 可深知彼（有自我参照） | 浅知彼为主，易误判场面 | **浅知彼可强**；深知彼受限（缺自我校准） | 浅也常不准 |
| **衡量阈值（建议）** | 自我误差≤25% 且 识人误差≤25% | 自我≤25% 且 识人>25% | 自我>25% 且 识人≤25% | 两者都>25% |
| **典型风险** | 被当成纯骗子；信任成本 | 错过机会；被低估/被利用 | 会看人不会看己；决策自欺 | 精致自我叙事；崩盘式透支 |
| **相处策略（简）** | 听包装比例，核验事实 | 主动问上限、给校准反馈 | 用人眼光，不轻信其自我定位 | 只看可核验结果，不听自我故事 |

## 二、概念定义表

| 术语 | 操作定义（可测） | 不是什么 |
|------|------------------|----------|
| **知己** | 知不知道自己在吹、吹了多少；宣称 vs 可核验事实的误差小，且能自觉标包装 | 不是「自信」或「谦虚」 |
| **知彼** | 知不知道别人能不能拆穿、别人自己吹了多少；对他人行为/虚实的预测可校准 | 不是「情商好」或「会说话」 |
| **浅知彼** | 观察外表、话术、利益、情绪、场面谁好骗 | 不等于看透长期动机 |
| **深知彼** | 判断动机、边界、长期行为；通常需要先有知己作参照 | 不知己时很难稳定达到 |
| **自我估值误差** | \|宣称资源/能力 − 事实\| / 事实 | 单次印象不算 |
| **识人误差** | 对他人预测 vs 事后结果的偏差 | 用自己动机套别人 = 投射，要扣分 |

## 三、四型行为对照表（你的解释）

| 类型 | 吹牛 | 自我定价 | 对别人 | 一句话 |
|------|------|----------|--------|--------|
| 知己知彼 | 可能很大 | 准，包装自觉 | 清楚识破难度与他人虚实 | 会吹牛，且知道自己在吹 |
| 知己不知彼 | 一般不吹 | 常低估 | 常误判别人/场面 | 清楚自己，看不清场 |
| 不知己知彼 | 不定 | 糊（虚高或虚低） | 看人往往准 | 会看人，看不清自己 |
| 不知己不知彼 | 当真虚高 | 10当12花 | 也看不清 | 精致自我定义，内外都糊 |

## 四、精确衡量总表

| 尺子 | 测什么 | 具体做法 | 达标参考 |
|------|--------|----------|----------|
| **A. 金额/资源校准** | 知己 | 让其说「我大概有多少」，对照事实 | 相对误差 ≤20–25% |
| **B. 吹牛自觉** | 知己 | 事后问：刚才几成包装？ | 能标出比例 ≈ 知己；当真 ≈ 不知己 |
| **C. 自我概率校准** | 知己 | 「这事我能成吗？概率？」多次复盘 | 说70%的事约七成发生 |
| **D. 低估/高估倾向** | 知己方向 | 连续5次自评 vs 结果 | 系统偏低→孤岛常见；系统偏高且不自知→迷雾 |
| **E. 拆穿预测** | 知彼 | 「他这话几成真？别人会不会信？」事后对照 | 误差 ≤25% |
| **F. 行为预测** | 知彼 | 回款/挖角/兑现等给概率，事后对照 | 同上校准 |
| **G. 动机归因** | 知彼深度 | 先写猜测动机，再看后续 | 对上加分；投射扣分 |

### 简分公式（可选）

| 分数 | 公式 | 用途 |
|------|------|------|
| 知己分 | `10 − 平均相对误差%×10`，不自知吹牛再扣2–3分 | 横轴 |
| 知彼分 | 对他人预测用同一套校准 | 纵轴 |
| 分型 | 近5–10次可复盘事件，按25%误差门槛落入四格 | 最终标签 |

## 五、四格落位规则表

| | **知彼高**（识人误差 ≤25%） | **知彼低**（>25% 或常猜错） |
|--|--|--|
| **知己高**（自我误差 ≤25%） | **明弈型** | **孤岛型** |
| **知己低**（自我误差 >25%） | **镜人型** | **迷雾型** |

**重要约束**

| 约束 | 说明 |
|------|------|
| 样本量 | 单次印象不可靠，至少约5次同类互动 |
| 可核验域 | 优先量钱、工期、回款、是否兑现；价值观/真心只能粗分 |
| 测量者偏差 | 先校准自己，再量别人，否则污染结果 |
| 深知彼上限 | 不知己可「会看人」（浅知彼），难稳定「看透人」（深知彼） |

## 六、现场快筛表（10题，✓/✗）

对一个人，近一段时间观察后打勾（知己题1–5，知彼题6–10）：

| # | 题目 | ✓ 倾向 |
|---|------|--------|
| 1 | 其自我介绍/报价与可查事实大体同级（误差不大） | 知己 |
| 2 | 被追问时能区分「事实 / 包装 / 愿景」 | 知己 |
| 3 | 事后承认过「那句有水分」 | 知己 |
| 4 | 不把偶然成功当成稳定能力 | 知己 |
| 5 | 生活支出/承诺与真实资源匹配（非长期10当12） | 知己 |
| 6 | 能提前说出谁在吹、场子里谁看不穿 | 知彼 |
| 7 | 对回款/兑现/挖角等预测多次大致准 | 知彼 |
| 8 | 较少用「我要是他我会…」硬套别人 | 知彼 |
| 9 | 能区分「别人真强」和「别人会演」 | 知彼 |
| 10 | 对陌生人也有可验证的准判断（非纯运气） | 知彼 |

**计分**：知己✓≥3 且 知彼✓≥3 → 明弈；仅知己高 → 孤岛；仅知彼高 → 镜人；都低 → 迷雾。

## 七、思想脉络（讨论结论一览）

| 序号 | 结论 |
|------|------|
| 1 | 原2×2（明弈/镜人/迷雾/孤岛）可保留 |
| 2 | 你的定义轴是：自我定价自觉 × 对他人虚实/识破的判断 |
| 3 | 不知己也可以知彼，但多半是**浅知彼**；深知彼通常要先知己 |
| 4 | 精确衡量的唯一路径：可观测误差 + 概率校准 + 复盘，不靠形容词 |
| 5 | 「有10当12花」是迷雾型的强信号；「敢吹但标得清包装」是明弈型信号；「不吹且低估」是孤岛型信号 |
